KubeLantern agent installed in namespace "{{ .Release.Namespace }}".

1. Make sure the namespace is enabled (the gateway only admits labelled namespaces):

     kubectl label namespace {{ .Release.Namespace }} kubelantern.io/enabled=true --overwrite

   With GitOps, set this label in the chart that creates your namespaces instead.

2. Watch it:

     kubectl -n {{ .Release.Namespace }} logs -f deploy/kubelantern-agent
